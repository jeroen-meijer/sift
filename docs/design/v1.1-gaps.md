## Toolbar / chrome

1. Remove toolbar buttons **Drag files**, **Analyze**, **Custom analysis…**. Drag is a gesture on selected rows; analyze / custom analysis belong on the context menu.
2. Design omni row has only Waveforms / Favorites / Columns. App already matches those toggles; drop the extra `library-toolbar` strip under OmniSearch.
3. Fake traffic lights stay out of the real Overlay titlebar (already fixed earlier).

## Folder sidebar

4. Every non-root folder needs a folder icon (`ph-folder` / open when selected). Roots keep hard-drives icon.
5. Expanded roots show a caret-down before the drive icon (design: `ph-bold ph-caret-down`). Collapsed roots show caret-right; children hide when collapsed.
6. Selected row: accent fill + 2px inset accent bar + accent icon tint (`#b5abfc`). Counts on selection use `#8b84ad`.
7. Plain folder text `#b2b6ca`; hover `#e9e9ed`. Root labels mono 11.5px / 500.
8. Sidebar bg stays `#12141f` (darker than main `#161826`). Ensure main never shares that fill.
9. **Tags** section under folders: collapsible header, color dots from taxonomy palette, counts, click sets tag filter (same as omni tag chip). Gear/sliders opens Tag Manager.
